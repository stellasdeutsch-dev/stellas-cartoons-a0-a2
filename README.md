# Stellas Deutsch — мультфильмы для A0–A2

Каталог мультфильмов и детских передач на немецком языке для начинающих.

**Сайт:** https://stellasdeutsch-dev.github.io/stellas-cartoons-a0-a2/
**Продвинутый уровень (B1–C1):** https://stellasdeutsch-dev.github.io/stellas-cartoons-b1-c1/

Для каждого тайтла: постер, уровень, длина серии, темп речи, тема грамматики,
лексика и ссылки на просмотр (в приоритете — бесплатные: ARD, ZDF, KiKA, YouTube).

Фильтрация по уровню, формату, темпу речи, теме и грамматике; сортировка и группировка.

Постеры и метаданные — [TMDB](https://www.themoviedb.org/). Проект не связан с TMDB.
